# Curso de Python

Este repositório contém os exercícios que realizei durante um curso de Python focado nos fundamentos da linguagem. O curso foi ministrado pelo **Gustavo Guanabara** na plataforma **Curso em Vídeo**.

## Conteúdo

A pasta `exercicios/` contém arquivos Python individuais, cada um representando a solução para um exercício específico. Os exercícios cobrem os seguintes tópicos básicos de Python:

*   **Tipos de Dados:** Inteiros, floats, strings, booleanos, listas, tuplas, dicionários e conjuntos.
*   **Operadores:** Aritméticos, de comparação, lógicos e de atribuição.
*   **Estruturas de Controle:** `if`, `else`, `elif`, loops `for` e `while`.
*   **Funções:** Definição e chamada de funções, argumentos e retorno de valores.
*   **Entrada e Saída:** Ler dados do usuário (`input()`) e imprimir resultados (`print()`).
*   **Manipulação de Strings:** Formatação, slicing e métodos de string.
*   **Listas e Tuplas:** Criação, acesso, manipulação e iteração.
*   **Dicionários:** Criação, acesso, manipulação e iteração.

## Organização

*   `exercicios/`: Pasta contendo todos os arquivos de exercícios.
    *   `ex001.py`: Exemplo de nome de arquivo para o primeiro exercício.
    *   `ex002.py`: Exemplo de nome de arquivo para o segundo exercício.
    *   ...

## Observações

Estes exercícios foram criados para praticar os conceitos básicos de Python ensinados no curso do Gustavo Guanabara no Curso em Vídeo. Eles podem não ser soluções otimizadas ou completas, mas servem como um registro do meu aprendizado durante o curso.
